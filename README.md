## Operating platforms

### Saulius Systems

AI strategy, adoption, and operational architecture for teams that need a practical path from AI ambition to governed delivery. My work covers AI readiness, use-case discovery, implementation roadmaps, and sustainable delivery controls.

### WorkTravel Academy

An AI-first membership and learning ecosystem with member onboarding, community incentives, Local Hubs, CRM journeys, and controlled Wix-to-GCP workflow automation.

### SquadMatch

A human-in-the-loop B2B talent-matching platform. The delivery model uses guarded automation for preliminary squad shortlisting, deterministic matching, approval gates, and strict data boundaries.

### AI Twin

A governed multi-agent operating platform using Google Cloud and Vertex AI Agent Engine workflows, knowledge continuity, observability, and role-specific AI workers.

## Delivery discipline

I combine executive-level operating design with hands-on implementation across Google Cloud, Vertex AI, Cloud Run, Firestore, Python, FastAPI, TypeScript, GitHub, Google Workspace, Wix, Webflow, and business process automation.

The control pattern is consistent: human review for consequential decisions; deterministic checks for repeatable controls; release readiness and audit trails for production work; and synthetic-data validation before real-world use.

## Selected implementation scope

The AI Twin platform includes multi-agent deployment, curated knowledge continuity, service observability, and explicit role and tool boundaries. The SquadMatch guarded-automation pilot uses an issue-tracking framework to document deterministic matching logic and approval workflows.
